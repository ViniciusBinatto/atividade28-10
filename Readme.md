# Sistema de Gestão — CRUD Node.js

## Nome do Projeto

Sistema de Gestão com CRUD e reestilização utilizando Inteligência Artificial.

## Integrantes

- Vinicius Drigo Binatto
- Isabela Stetz Tavernaro Camargo

## Objetivo

O objetivo deste projeto foi desenvolver um sistema CRUD utilizando Node.js, no qual é possível cadastrar, listar, editar e excluir informações.

Além de concluir as funcionalidades do sistema, a atividade também pediu que fizéssemos uma mudança no visual da aplicação utilizando uma ferramenta de Inteligência Artificial como apoio.

## Tecnologias Utilizadas

- Node.js
- Express
- EJS
- HTML e CSS
- Bootstrap 5
- GitHub
- Render
- ChatGPT

## Funcionalidades

O sistema possui páginas para gerenciar clientes, fornecedores, produtos e categorias.

As principais funcionalidades são:

- Cadastrar informações.
- Listar os registros cadastrados.
- Editar informações existentes.
- Excluir registros.
- Navegar entre as páginas do sistema.
- Utilizar formulários para inserir e atualizar informações.

## Prompt Utilizado

Para ajudar na mudança do visual, utilizamos o seguinte prompt no ChatGPT:

"Estou desenvolvendo um CRUD utilizando Node.js, Express, EJS e Bootstrap. Quero mudar completamente o visual do sistema, deixando a interface mais moderna e organizada, com tema escuro e detalhes em roxo. Quero melhorar os formulários, as tabelas, os botões e os cartões da página inicial, além de deixar o sistema mais agradável de usar e adaptado para celulares. Me oriente passo a passo, indicando quais arquivos preciso alterar e fornecendo códigos que funcionem com a estrutura que já tenho. É importante manter as funcionalidades do CRUD e não alterar as rotas sem necessidade."

## Uso da Inteligência Artificial

Utilizamos o ChatGPT para ajudar na parte visual do projeto e para tirar dúvidas durante as alterações.

A ferramenta sugeriu algumas mudanças no CSS, nos formulários, nas tabelas e nos botões. Também ajudou a identificar problemas no carregamento do arquivo CSS e a montar a página de edição de produtos, que ainda não existia no projeto.

As sugestões foram analisadas e adaptadas de acordo com os arquivos que já tínhamos. Depois das alterações, precisamos conferir se o visual ficou correto e se as funcionalidades continuaram funcionando.

## Alterações Sugeridas pela IA

A IA sugeriu:

- Criar um tema escuro com tons de cinza e detalhes em roxo.
- Melhorar a aparência dos formulários de cadastro e edição.
- Personalizar as tabelas e os botões.
- Mudar as cores dos cartões da página inicial.
- Melhorar a organização dos elementos.
- Ajustar o visual para telas menores.
- Corrigir o caminho de carregamento do arquivo CSS.
- Criar um formulário para editar produtos utilizando os mesmos campos do cadastro.

## Alterações Implementadas pelo Grupo

Durante o trabalho, fizemos alterações nos arquivos CSS e EJS para personalizar o visual do sistema.

Entre as mudanças realizadas, estão:

- Alteração das cores para um tema escuro.
- Uso de detalhes em roxo nos botões e nos campos.
- Personalização dos cartões e das tabelas.
- Ajustes nos formulários.
- Criação do arquivo de edição de produtos com os campos nome, descrição, preço, estoque e categoria.
- Correção do caminho do arquivo CSS no cabeçalho da aplicação.

Também utilizamos as orientações do ChatGPT para entender os erros encontrados e fazer os ajustes necessários.

As alterações finais foram adaptadas ao nosso projeto, mantendo a estrutura de rotas e as funcionalidades existentes.
